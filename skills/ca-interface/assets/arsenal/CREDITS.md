# Créditos e licenças de terceiros do arsenal

Os componentes de `componentes/` foram criados por outras pessoas e publicados no [21st.dev](https://21st.dev). Este arsenal guarda cópias adaptadas para servir de ponto de partida para protótipos, sob a licença que cada autor declarou na página do componente. Os termos do 21st.dev pedem link visível para a página original: ele está em cada linha abaixo. Pesquisa de licenças feita em 16/11/2026; detalhes em `componentes/LICENCAS.md`.

Nada aqui deve ser apresentado como obra própria nem usado como base de treino de modelos de IA (termos do 21st.dev, seção 3).
